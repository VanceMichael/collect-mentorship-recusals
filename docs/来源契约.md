# 资料提供方的格式

`/school/roles.html` 带机构、门户号、导师注册号和开放分钟，注册号是个人级身份。`/teams.json` 性质和团队派员分版给出，区间左闭右开。`/registry.csv` 的案件项给归属编号及用途，登记 treat=recuse 指指定个人需回避，unknown 指适用性未确认，落地会议须能追溯联合子团队。
`/appointment` 由院校门户提供，按院校、受理编号、轮次查出记录。回读含暂存、确认、释放和独立签认。档期跨角色不能重复使用，门户回执只说明对应入口的状态。
`/schedule` 是院校预约录入网页，时间写当地分钟区间，导师页号随院校变化。返回申请号后以 `/appointment` 回读为准。
